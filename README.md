<h1 align="center"><strong>Class Angular Distortion Index</strong></h1>


Repository accompanying the paper "Class Angular Distortion Index for Dimensionality Reduction".

# Requirements

- Python 3.11
- pip


# Setup

### 1. Clone the repository:

```bash
git clone https://github.com/KaviruGunaratne/cadi.git
cd cadi
```

### 2. Create a virtual environment
```bash
python3.11 -m venv venv
```

### 3. Activate the environment
#### Linux / macOS
```bash
source venv/bin/activate
```
#### Windows / PowerShell
```bash
venv\Scripts\Activate.ps1
```
### 4. Install dependencies
```
pip install -r requirements.txt
```

# Using CADI


```python
from metrics import CADI
from sklearn.datasets import load_wine
from sklearn.manifold import TSNE

X, labels = load_wine(return_X_y=True)
Y = TSNE().fit_transform(X)

cadi_score = CADI(X, Y, labels)
print(cadi_score)

```


# Run experiments

## Run scripts

Run the following scripts in the given order to generate all the information used to generate the experimental results.

- `load_data.py`
    - Generate datasets and projections (stored in the created `data` directory)
- `calculate_metrics.py`
    - Compute cluster-level metric scores for stored projections
- `stability_check.py`
    - Calculate CADI multiple times for all datasets to check stability of score under random sampling
- `calculate_time_taken.py`
    - Compute time taken for different metrics for different dataset sizes

## Generate figures and tables

Figures and tables from the paper can be generated by running the Jupyter notebooks in the `notebooks` directory. The functions of each Jupyter notebook are as follows:

- `metric_stats.ipynb`
    - Create tables and figures that show the various scores assigned to each projection by the various cluster-level metrics considered
- `dataset_analysis.ipynb`
    - Analyzes properties of a select number of datasets to justify CADI's scores. Relevant figures are also saved in the `figs` directory.
- `ADI-vs-CADI.ipynb`
    - Compares the properties of CADI and ADI (CADI without constrained triplet selection)
- `figure2.ipynb`
    - Generates figures that plot the time taken for each metric on each dataset, as well as strip plots demonstrating the stability of CADI on all datasets. Generated figures are stored in the `figs` directory.
- `hyperparameter_analysis.ipynb`
    - Visualizes how CADI changes with different hyperparameter choices of UMAP on a given dataset.
